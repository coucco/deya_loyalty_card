# Карта лояльности ТРЦ «Дея»

Приложение для покупателей, сервер с логикой баллов, страницы для касс и админа, плагин для касс Set Retail 10 в гипермаркете.

Покупатель показывает QR из приложения на кассе гипермаркета → после пробития чека плагин сообщает серверу → баллы начисляются → на 3 этаже (кино, боулинг) ими можно платить. Проценты меняются в админке без правки кода.

## Быстрый пробный запуск (без Docker, 1 минута)

Нужен Node.js 22.13+.

```bash
cd server
SEED_DEMO=1 node --disable-warning=ExperimentalWarning src/index.js
```

Откройте `http://localhost:3000`. Код входа печатается в консоль сервера (в бою вместо этого настоящие СМС). Токен админки (`/admin`) печатается при старте. Проценты в этом режиме демонстрационные (5 % и 10 %).
