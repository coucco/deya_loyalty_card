# Карта лояльности ТРЦ «Дея»

Приложение для покупателей, сервер с логикой баллов, страницы для касс и админа, плагин для касс Set Retail 10 в гипермаркете.

Покупатель регистрируется в приложении и получает карту из пула номеров, заведённых в Set10 → показывает QR (или штрихкод) на кассе гипермаркета → Set10 даёт «цену 3» по карте → после пробития чека плагин сообщает серверу → баллы начисляются → тратить их можно на 3 этаже (кино, боулинг) и, по настройке, в самом гипермаркете (до N % чека). Пластиковые карты копят баллы до привязки к телефону в приложении. Проценты и лимиты меняются в админке без правки кода.

## Быстрый пробный запуск (без Docker, 1 минута)

Нужен Node.js 22.13+.

```bash
cd server
SEED_DEMO=1 node --disable-warning=ExperimentalWarning src/index.js
```

Откройте `http://localhost:3000`. Код входа печатается в консоль сервера (в бою вместо этого настоящие СМС). Токен админки (`/admin`) печатается при старте. Проценты в этом режиме демонстрационные (5 % и 10 %).
