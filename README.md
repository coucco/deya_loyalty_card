# Карта лояльности ТРЦ «Дея»

Приложение для покупателей, сервер с логикой баллов, страницы для касс и админа, плагин для касс Set Retail 10 в гипермаркете.

Покупатель регистрируется в приложении и получает карту из пула номеров, заведённых в Set10 → показывает QR (или штрихкод) на кассе гипермаркета → Set10 даёт «цену 3» по карте → после пробития чека плагин сообщает серверу → баллы начисляются → тратить их можно на 3 этаже (кино, боулинг) и, по настройке, в самом гипермаркете (до N % чека). Пластиковые карты копят баллы до активации на кассе (телефон покупателя + код из СМС). Проценты и лимиты меняются в админке без правки кода.

> **Какие документы актуальны и кому какой — `docs/README.md`.**

## Что здесь лежит

| Папка/файл | Что это |
|---|---|
| `server/` | сервер: начисление, возвраты, списание, вход по СМС, админ-API (Node.js 22 без внешних библиотек) |
| `web/` | приложение покупателя (PWA), страница кассира `/cashier`, админка `/admin` |
| `set10-bonus-plugin/` | плагины для касс Set10 в одном jar: лояльность (начисление, списание) и карты (активация пластика по СМС, поиск по телефону); комплект для установки - `dist/` |
| `docs/` | документы - список и кому какой: `docs/README.md` |
| `e2e/` | браузерный тест и тест «плагин - сервер» |
| `Dockerfile`, `docker-compose.yml`, `deploy/`, `.env.example`, `Makefile`, `scripts/` | запуск и обслуживание |

## Быстрый пробный запуск (без Docker, 1 минута)

Нужен Node.js 22.13+.

```bash
cd server
SEED_DEMO=1 node --disable-warning=ExperimentalWarning src/index.js
```

Откройте `http://localhost:3000`. Код входа печатается в консоль сервера (в бою вместо этого настоящие СМС). Токен админки (`/admin`) печатается при старте. Проценты в этом режиме демонстрационные (5 % и 10 %).
