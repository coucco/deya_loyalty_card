# Развёртывание сервера лояльности

Что нужно: любой недорогой сервер (VPS) **в России** с Linux, 1 ядро / 1 ГБ памяти достаточно, домен, СМС-провайдер. Через Docker (рекомендуется) или напрямую.

> **Честно о проверке.** Сервер, веб-приложение и их автотесты запускались в среде разработки. **Образ Docker и HTTPS через Caddy в той среде собрать не удалось** (там нет демона Docker): синтаксис `docker-compose.yml` проверен (`docker compose config`), но первая сборка пройдёт у вас. Если что-то не взлетит — это самое вероятное место, смотрите «Если что-то не работает» ниже.

## 0. Что приготовить заранее

| Что | Зачем |
|---|---|
| Сервер Linux (Ubuntu 22.04/24.04) в РФ с открытыми портами 80 и 443 | Хостинг. Данные граждан РФ хранятся в РФ (152-ФЗ) |
| Домен (например `loyalty.deya-trc.ru`), A-запись на IP сервера | Адрес приложения и HTTPS |
| СМС-провайдер с HTTP-API (например SMS.ru, SMSC.ru, SMS Aero) | Отправка кодов входа. Без него клиенты не смогут войти |
| Решение по процентам | Задаётся уже после запуска в админке, не блокирует развёртывание |

## 1. Вариант А: Docker (рекомендуется)

```bash
# 1. Установить Docker (один раз)
curl -fsSL https://get.docker.com | sh

# 2. Получить проект на сервер (распакуйте архив deya-loyalty.zip в /opt/deya-loyalty)
cd /opt/deya-loyalty

# 3. Настройки
cp .env.example .env
nano .env        # заполнить DOMAIN, ADMIN_TOKEN, APP_SECRET, SMS_*
#   секреты можно сгенерировать:  openssl rand -hex 24

# 4. Запуск
docker compose up -d --build
docker compose logs -f app       # должно появиться «Дея-лояльность: порт 3000»
```

Через минуту-две откройте `https://<ваш домен>/`: должен открыться экран входа. Сертификат HTTPS выпускается автоматически (нужен доступный из интернета порт 80).

Админка: `https://<домен>/admin`, вход по `ADMIN_TOKEN`.

## 2. Вариант Б: без Docker

Нужен Node.js **22.13 или новее** (в нём есть встроенный SQLite).

```bash
cd /opt/deya-loyalty/server
export NODE_ENV=production PORT=3000 DB_FILE=/var/lib/deya/deya.db PUBLIC_DIR=/opt/deya-loyalty/web TRUST_PROXY=1
export ADMIN_TOKEN=... APP_SECRET=... SMS_PROVIDER=http SMS_HTTP_URL='https://...{phone}...{text}'
node --disable-warning=ExperimentalWarning src/index.js
```

Чтобы сервер перезапускался сам, оформите его службой systemd (`/etc/systemd/system/deya.service`, `ExecStart=/usr/bin/node --disable-warning=ExperimentalWarning /opt/deya-loyalty/server/src/index.js`, `Restart=always`, переменные в `EnvironmentFile=`). HTTPS поставьте перед ним любым обратным прокси (Caddy или nginx + certbot).

## 3. Первичная настройка (одинакова для обоих вариантов)

1. Откройте `/admin`, введите `ADMIN_TOKEN`.
2. В разделе **«Точки и проценты»** уже есть «Гипермаркет», «Кино», «Боулинг» с процентами **0** (в бою демо-проценты не включаются). Реальные цифры задайте, когда будут готовы: «Начисление, %» для гипермаркета и «Макс. оплата баллами, % чека» для кино и боулинга. Они действуют сразу.
3. Нажмите **«Новый ключ»** у «Гипермаркета». Ключ показывается один раз, скопируйте: он нужен для плагина (`api.key`). Так же выпустите ключи кино и боулингу, если будут пользоваться страницей `/cashier`.
4. Проверьте вход: откройте приложение с телефона, введите свой номер, должно прийти СМС.
5. Проверьте начисление без кассы: откройте `/cashier` на телефоне, введите ключ точки «Гипермаркет», найдите себя по номеру карты (в приложении: Профиль → «Номер карты») и начислите тестовый чек. В приложении должно появиться начисление.

## 4. Резервные копии (обязательно)

Баланс клиентов — это деньги. Делайте копию ежедневно:

```bash
# Docker:
docker compose exec -T app node scripts/backup.mjs /data/deya.db /data/backup-$(date +%F).db
# cron (каждую ночь в 3:30), хранить копии вне сервера:
30 3 * * *  cd /opt/deya-loyalty && make backup
```

Копия делается без остановки сервера и проверяется (`PRAGMA integrity_check`). **Обязательно периодически копируйте файлы `backup-*.db` на другой сервер или в облако** и хотя бы раз проверьте восстановление: остановить сервер, подложить копию вместо `deya.db`, запустить, зайти в админку.

Проверка целостности в любой момент: `node scripts/reconcile.mjs <файл БД>` (или блок «Расхождений журнала» в админке должен быть 0).

## 5. Обновление

```bash
cd /opt/deya-loyalty && <заменить файлы новой версией>
docker compose up -d --build        # данные в томе deya-data сохраняются
```

Схема БД создаётся автоматически и совместима с прежними данными (таблицы только добавляются; перед обновлением всё равно сделайте копию).

## 6. Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DOMAIN` | — | домен для HTTPS (Caddy) |
| `ADMIN_TOKEN` | — (в бою обязателен, ≥ 24 символов) | пароль админки |
| `APP_SECRET` | — (в бою обязателен) | секрет хэширования кодов |
| `SMS_PROVIDER` | `console` | `http` в бою (`console` в бою запрещён: коды попадали бы в лог) |
| `SMS_HTTP_URL`, `SMS_HTTP_AUTH` | — | шаблон GET-запроса провайдера и заголовок Authorization |
| `CARD_PREFIX`, `CARD_LENGTH` | `2000`, `13` | формат номеров карт (в плагине тот же префикс: `card.prefix`) |
| `OTP_TTL_SEC`, `OTP_MAX_ATTEMPTS`, `OTP_RESEND_SEC`, `OTP_PER_HOUR` | 300, 5, 60, 5 | параметры кодов |
| `SESSION_DAYS` | 90 | на сколько дней клиент остаётся в приложении |
| `HOLD_TTL_SEC` | 600 | сколько держится резерв баллов при списании |
| `RATE_LIMIT_PER_MIN` | 120 | запросов в минуту с одного адреса к клиентскому API |
| `SEED_DEMO` | выкл. в бою | только для пробного запуска: демо-проценты 5 % и 10 % |

## 7. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Контейнер `app` перезапускается, в логах «нужен ADMIN_TOKEN» / «нельзя SMS_PROVIDER=console» | заполнить `.env`; сервер намеренно отказывается стартовать в бою без секретов и СМС |
| Нет HTTPS, Caddy пишет про сертификат | домен должен указывать на этот сервер, порты 80/443 открыты |
| Клиент нажимает «Получить код», пишет «Не удалось отправить код» | неверный `SMS_HTTP_URL` или баланс у провайдера; смотрите `docker compose logs app` |
| «Неверный ключ доступа» в логе плагина | ключ точки перевыпущен: старый перестаёт работать, обновите `api.key` в настройках плагина |
| Баллы не начисляются, в логах 422 | карты нет в базе или она закрыта (клиент удалил аккаунт) |
