# Что делать сейчас: от аренды сервера до чека с баллами

Один документ на весь путь. Справочник по каждому параметру (откуда, вид, на что влияет) — `docs/PARAMETERS.md`; заглядывать туда, только если нужно что-то менять сверх этого списка.

Сервер лояльности — **один VPS**: на нём приложение клиента (`/`), админка (`/admin`), страница кассира (`/cashier`) и API для плагина (`/api/...`).

## Шаг 0. До аренды — один вопрос команде Set10 (5 минут)
Может ли **тестовая касса** открыть в браузере или `curl` любой внешний сайт по HTTPS (например `https://ya.ru`)?
* **Да** → дальше по шагам.
* **Нет** (касса в закрытой сети) → попросить открыть исходящий HTTPS (порт 443) с касс на будущий домен сервера. Без этого плагин не достучится до сервера.

## Шаг 1. Аренда и регистрации (вы, ~30 минут)

| # | Что сделать | Что записать |
|---|---|---|
| 1.1 | Арендовать VPS **в РФ** (Timeweb Cloud, Selectel, REG.RU): Ubuntu 24.04, 1 ядро, 2 ГБ, 20 ГБ диска. В файрволе хостинга открыть порты **22, 80, 443** | IP-адрес, пароль root |
| 1.2 | У регистратора домена ТРЦ → DNS → добавить запись: тип `A`, имя `test-loyalty`, значение — IP | адрес `test-loyalty.<домен ТРЦ>` |
| 1.3 | SMS.ru: кабинет уже есть, пополнить баланс (без пополнения СМС уходят только на ваш номер) | api_id |

Проверка через 5–30 минут: `ping test-loyalty.<домен>` показывает IP сервера.

## Шаг 2. Установка на VPS (~20 минут)

```bash
ssh root@<IP>
curl -fsSL https://get.docker.com | sh
git clone -b claude/adoring-wright-pmizlz https://github.com/coucco/deya_loyalty_card /opt/deya-loyalty
cd /opt/deya-loyalty
cp .env.example .env
openssl rand -hex 24      # строка 1 → ADMIN_TOKEN
openssl rand -hex 24      # строка 2 → APP_SECRET
nano .env
```
Репозиторий закрытый — `git clone` спросит логин: укажите логин GitHub, а вместо пароля — токен (GitHub → Settings → Developer settings → Personal access tokens, право «Contents: read»). Либо скачайте архив ветки на компьютер и загрузите на сервер: `scp deya.zip root@<IP>:/opt/`.

**В `.env` поменять только эти строки** (остальное оставить как есть):

| Строка | Что вписать | На что влияет |
|---|---|---|
| `DOMAIN=` | `test-loyalty.<домен ТРЦ>` (без `https://`) | HTTPS-сертификат, адрес всего сервиса |
| `ADMIN_TOKEN=` | строка 1 от `openssl` | **пароль от `/admin`** — сохраните в менеджере паролей |
| `APP_SECRET=` | строка 2 от `openssl` | подпись кодов из СМС и кодов пластика; **после запуска не менять** |
| `SMS_HTTP_URL=` | `https://sms.ru/sms/send?api_id=<ваш api_id>&to={phone}&msg={text}&json=1` | отправка СМС; `{phone}`, `{text}`, `json=1` не трогать |

Уже стоят правильные значения: `SMS_PROVIDER=http`, `CARD_ISSUE_MODE=pool`, контакты поддержки, сроки копий и журнала.

Запуск:
```bash
docker compose up -d --build
docker compose logs -f app        # ждать строку «Дея-лояльность: порт 3000», выйти Ctrl+C
```
Проверка: в браузере `https://test-loyalty.<домен>/healthz` → `{"ok":true}`; `https://test-loyalty.<домен>/` → экран входа.

> Образ Docker собирается впервые. Если `up` упал — пришлите вывод `docker compose logs app`.

## Шаг 3. Админка (~10 минут)
`https://test-loyalty.<домен>/admin` → вставить `ADMIN_TOKEN` → «Войти».

1. «Точки и проценты» → «Гипермаркет»: «Начисление, %» = `5`, «Макс. оплата баллами, % чека» = `5` → «Сохранить».
2. Там же «Новый ключ» → скопировать `pk_…` (показывается один раз; потеряли — выпустить новый и заменить в Set10).
3. «Пул карт»:
   * тип «виртуальные» → диапазон `999000000000001` по `999000000000007` → «Загрузить диапазон»;
   * тип «пластиковые» → диапазон `999000000000008` – `999000000000010` → «Загрузить диапазон».
4. С телефона: `https://test-loyalty.<домен>` → свой номер → код из СМС → в профиле карта `9990000000000…` и ID профиля.

## Шаг 4. Касса Set10 (команда внедрения)
Передать команде: **`server.url`** = `https://test-loyalty.<домен>/api/v1/accruals` и **ключ `pk_…`** (лично, отдельно от файлов). Jar 1.2.1 и `INSTALL.pdf` у команды уже есть — дальше всё по `INSTALL.pdf`: настройки плагина (в т.ч. `card.prefix=999`, `redeem.enabled=да`, `log.trace=да`), наш плагин последним в порядке провайдеров, перезапуск кассы.

## Шаг 5. Первый сквозной чек
1. Телефон: приложение → «Показать QR на кассе».
2. Касса: отсканировать QR → товар → подытог → оплата → чек пробит.
3. Через ≤ 5 секунд в приложении «+N баллов».
4. Если баллов нет — смотреть по порядку:
   * журнал плагина на кассе `plugins/deya-logs/deya-plugin.log` (строки `вызван …`);
   * админка → «Журнал действий» (дошёл ли запрос от `point:hypermarket`);
   * `docker compose logs app` на VPS.

Дальше — этапы и критерии по `docs/TEST_PLAN.md`.

## Что никому не передавать
`.env`, `ADMIN_TOKEN`, `APP_SECRET`, api_id SMS.ru, пароль root от VPS.
