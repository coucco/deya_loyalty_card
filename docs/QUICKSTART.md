# С нуля до работающей админки: по шагам

Всё — один сервер: он отдаёт приложение (`/`), админку (`/admin`), страницу кассира (`/cashier`) и API для кассы (`/api/...`).

> Полный справочник параметров (откуда взять, вид, зачем) — `docs/PARAMETERS.md`.

## Порядок для теста (кто и что делает)

| # | Кто | Что | Результат |
|---|---|---|---|
| 1 | Владелец (вы) | Поднять сервер лояльности: VPS, домен, `.env`, `docker compose up -d --build` (шаги 1–2 ниже) | `https://<домен>/healthz` → `{"ok":true}` |
| 2 | Владелец | Админка `/admin`: проценты «Гипермаркета», «Новый ключ» → `pk_…`; «Пул карт» → тестовые карты | ключ и карты готовы |
| 3 | Владелец → команда | Передать команде: `DeyaBonusAccrualPlugin.jar` + `INSTALL.pdf` + адрес `https://<домен>/api/v1/accruals` + ключ `pk_…` (ключ — отдельно, лично) | |
| 4 | Команда внедрения | Положить jar на сервер Set10 и тестовую кассу; в «Внешних процессингах» вписать `server.url`, `api.key` и остальные настройки из `INSTALL.pdf` | |
| 5 | Команда внедрения | Плагин — последним в порядке провайдеров лояльности; перезапуск кассы | в логе кассы нет ошибок |
| 6 | Вместе | Телефон: регистрация в приложении → QR на кассе → чек → «+N баллов»; дальше `TEST_PLAN.pdf` | |

`.env` — настройки сервера лояльности, лежит только на VPS; в jar его нет, команде его не передавать (там секреты). Jar готов как есть: свои настройки плагин получает в Set10.

## 1. Сервер и домен (один раз)
1. Арендовать VPS **в России** (Timeweb Cloud, Selectel, REG.RU и т.п.): Ubuntu 24.04, 1 ядро, 1–2 ГБ. Записать **IP-адрес**.
2. В панели регистратора домена (где куплен, например, `deya-trc.ru`) открыть **DNS** и добавить запись:
   `Тип: A` · `Имя: loyalty` · `Значение: <IP сервера>`. Через 5–30 минут адрес `loyalty.deya-trc.ru` начнёт вести на сервер (проверка: `ping loyalty.deya-trc.ru` показывает этот IP).
3. Зарегистрироваться у СМС-провайдера (например SMS.ru) и взять из личного кабинета API-ключ и ссылку на отправку. Без СМС сервер в боевом режиме не запустится.

## 2. Установка (на сервере)
```bash
ssh root@<IP сервера>
curl -fsSL https://get.docker.com | sh
git clone -b claude/adoring-wright-pmizlz https://github.com/coucco/deya_loyalty_card /opt/deya-loyalty
cd /opt/deya-loyalty
cp .env.example .env
openssl rand -hex 24      # выполнить два раза: первая строка — ADMIN_TOKEN, вторая — APP_SECRET
nano .env
```
В `.env` заполнить:

| Строка | Что вписать |
|---|---|
| `DOMAIN=` | `loyalty.deya-trc.ru` |
| `ADMIN_TOKEN=` | первая строка от `openssl` — **это пароль от админки, сохраните его** |
| `APP_SECRET=` | вторая строка (никогда не менять после запуска) |
| `SMS_HTTP_URL=` | ссылка провайдера, где вместо номера `{phone}`, вместо текста `{text}` |
| `CARD_ISSUE_MODE=` | `pool` |

Запуск: `docker compose up -d --build`, затем `docker compose logs -f app` — должна появиться строка `Дея-лояльность: порт 3000`. Через 1–2 минуты `https://loyalty.deya-trc.ru` открывает экран входа (сертификат HTTPS выпускается сам; порты 80 и 443 должны быть открыты).

## 3. Админка
1. Открыть `https://loyalty.deya-trc.ru/admin`, в поле «Токен администратора» вставить `ADMIN_TOKEN` из `.env` → «Войти».
2. «Точки и проценты» → «Гипермаркет»: «Начисление, %» = 5, «Макс. оплата баллами, % чека» = 5 → «Сохранить».
3. Там же «Новый ключ» → скопировать ключ `pk_…` (показывается **один раз**; потеряли — выпустить новый и заменить в Set10).
4. «Пул карт»: тип «виртуальные» → диапазон `999000000000001` … `999000000000007` → «Загрузить диапазон»; тип «пластиковые» → список
   `999000000000008;1234`, `999000000000009;2345`, `999000000000010;3456` → «Загрузить список».

## 4. Касса Set10
В настройках плагина «Бонусы ТРЦ Дея»: `server.url` = `https://loyalty.deya-trc.ru/api/v1/accruals`, `api.key` = ключ `pk_…`. Остальное — по `set10-bonus-plugin/dist/INSTALL.md`.

## 5. Проверка
С телефона открыть `https://loyalty.deya-trc.ru` → номер → код из СМС → в профиле карта `9990000000000…`. Дальше — `docs/TEST_PLAN.md`.

**Тест и прод** — два одинаковых сервера с разными доменами (например `test-loyalty…` и `loyalty…`), своими `.env` и своими ключами. Обновление: `cd /opt/deya-loyalty && git pull && docker compose up -d --build`.
