# Все параметры по этапам: откуда взять, в каком виде, зачем

Сверено с кодом (`server/src/config.js`, `set10-bonus-plugin/src/main/resources/metainf.xml`). 🔒 — секрет: хранить у себя, в чат и почту не отправлять, команде внедрения не передавать.

|---|---|---|---|---|

| Домен | регистратор (если ТРЦ уже имеет домен — его поддомен) | `loyalty.deya-trc.ru` (бой), `test-loyalty.deya-trc.ru` (тест) | адрес приложения, админки, API | DNS, `DOMAIN` в `.env`, `server.url` в Set10 |
| DNS A-запись | создаёте сами в панели регистратора | `loyalty` → `<IP>` | домен ведёт на VPS | проверка: `ping <домен>` показывает IP |

| Тестовые карты Set10 | заводит команда Set10 / вы в Set10 (тип карт с «ценой 3») | `999000000000001`…`010` (15 цифр) | номера, которые узнаёт касса | админка → «Пул карт» |
| Коды активации пластика | придумываете / типография печатает на обороте | 4–6 цифр | защита привязки пластика к телефону | админка → «Пул карт» (`номер;код`) |

## Этап 2. Файл `.env` на VPS (`/opt/deya-loyalty/.env`)

Создаётся командой `cp .env.example .env`, редактируется `nano .env`, применяется `docker compose up -d`. **В jar его нет, команде не передаётся.**

**Обязательно заполнить:**

| Переменная | Откуда / как получить | Вид | Зачем |
|---|---|---|---|
| `DOMAIN` | ваш домен из этапа 1 | `loyalty.deya-trc.ru` (без https://) | HTTPS-сертификат (Caddy), ссылки в СМС |
| `ADMIN_TOKEN` 🔒 | `openssl rand -hex 24` на сервере | 48 символов `0-9a-f` | **пароль входа в `/admin`** (без него в бою сервер не стартует; минимум 24 символа) |
| `APP_SECRET` 🔒 | `openssl rand -hex 24` (второй раз) | 48 символов | подпись кодов из СМС и кодов активации пластика. **Не менять после запуска**: иначе загруженные коды активации перестанут подходить |
| `SMS_PROVIDER` | уже в шаблоне | `http` | в бою `console` запрещён |
| `SMS_HTTP_URL` 🔒 | шаблон + ваш api_id | `https://sms.ru/sms/send?api_id=…&to={phone}&msg={text}&json=1` | отправка СМС; `{phone}`, `{text}` не трогать, `json=1` обязателен |
| `CARD_ISSUE_MODE` | уже в шаблоне | `pool` | клиенты получают карты из пула номеров Set10 |

**Можно оставить по умолчанию:**

| Переменная | По умолчанию | Зачем / когда менять |
|---|---|---|
| `SUPPORT_PHONE`, `SUPPORT_EMAIL` | `+7 929 838-45-16`, `timurshokarov1001@gmail.com` | контакты поддержки в приложении |
| `PUBLIC_URL` | `https://$DOMAIN` | ссылка на правила в СМС активации, если адрес другой |
| `TRUST_PROXY` | `1` | сервер за Caddy (не менять) |
| `SMS_HTTP_AUTH` | пусто | заголовок авторизации, если другой провайдер его требует |
| `POS_HOLD_TTL_SEC` | `1800` | сколько живёт резерв баллов под чек гипермаркета (подытог → оплата) |
| `HOLD_TTL_SEC` | `600` | резерв на 3 этаже |
| `BACKUP_KEEP_DAYS` | `14` | сколько дней хранить ежедневные копии БД (`BACKUP_DIR=/backups` задан в docker-compose) |
| `AUDIT_KEEP_DAYS` | `1095` | срок хранения журнала действий (3 года) |
| `DOCS_VERSION`, `DOC_*_URL` | `1`, `/legal/*.html` | когда юрист даст тексты: ссылки на документы и +1 к версии (версия пишется в журнал согласий) |
| `OTP_TTL_SEC`, `OTP_RESEND_SEC`, `OTP_PER_HOUR`, `OTP_MAX_ATTEMPTS` | 300 / 60 / 5 / 5 | жизнь кода из СМС, пауза перед повтором, лимит СМС в час на номер, попыток ввода |
| `SESSION_DAYS` | `90` | сколько дней клиент остаётся залогинен |
| `RATE_LIMIT_PER_MIN` | `120` | защита от перебора |
| `REDEEM_CONFIRM_ATTEMPTS` | `5` | попыток ввести код подтверждения на 3 этаже |
| `PORT`, `DB_FILE`, `PUBLIC_DIR`, `NODE_ENV`, `BACKUP_DIR` | заданы в Dockerfile/compose | не трогать |
| `CARD_PREFIX`, `CARD_LENGTH`, `SEED_DEMO` | — | только для пробного запуска без Set10 |

## Этап 3. Админка (`https://<домен>/admin`, вход по `ADMIN_TOKEN`)

| Что | Где в админке | Вид | Зачем | Куда идёт |
|---|---|---|---|---|
| Ключ точки «Гипермаркет» 🔒 | «Точки и проценты» → «Гипермаркет» → «Новый ключ» (показывается один раз) | `pk_…` | плагин кассы доказывает серверу, что он «Гипермаркет» | Set10 → `api.key` (передать команде лично) |
| Ключи «Кино», «Боулинг» 🔒 | там же, у своих строк | `pk_…` | вход на `/cashier` на 3 этаже | вводится на планшете кассира |
| Процент начисления | «Точки и проценты» → «Начисление, %» | число, напр. `5` | сколько баллов за покупку | действует сразу |
| Макс. оплата баллами | там же | `% чека`, напр. `5` | лимит списания в гипермаркете / на 3 этаже | действует сразу |
| Код подтверждения | галочка у точки 3 этажа | да/нет | списание только с кодом из приложения клиента | |
| Правила «цены 3» | «Правила расчёта» | галочки + id акций Set10 через запятую | начислять/списывать ли на товары со скидкой Set10 | id акций — из Set10 или из лога (`log.payload`) |
| 1 балл = N ₽, округление | «Правила расчёта» | `1`, «до ближайшего» | курс баллов | |
| Пул карт | «Пул карт» | диапазон `с`/`по` или строки `номер[;код]`, тип виртуальные/пластиковые | номера карт для выдачи | — |

## Этап 4. Set10: настройки плагина («Интеграция → Внешние процессинги» → «Бонусы ТРЦ Дея»)

Вносит команда внедрения. Jar менять не нужно — всё задаётся здесь.

| Ключ | Откуда | Тест | Бой | Зачем |
|---|---|---|---|---|
| `server.url` | ваш домен + `/api/v1/accruals` | `https://test-loyalty…/api/v1/accruals` | `https://loyalty…/api/v1/accruals` | адрес сервера (остальные адреса выводятся из него) |
| `api.key` 🔒 | админка, этап 3 | ключ тест-сервера | ключ боевого | доступ к серверу |
| `point.id` | — | `hypermarket` | `hypermarket` | id точки |
| `card.prefix` | начало номеров ваших карт | `999` | префикс боевых диапазонов | отличать карты ДЕЯ от других |
| `enabled` | — | да | да | аварийный выключатель |
| `redeem.enabled` | — | да | по решению | списание баллов в чеке |
| `redeem.mode` | — | `both` | `auto` / `cashier` / `both` | автосписание по согласию клиента / кнопка кассира |
| `card.mode` | итог этапа 2b плана | `internal`, затем `external` | по итогам теста | см. `SET10_PLUGINS.md` |
| `card.activation` | — | да | да | активация пластика на кассе по СМС |
| `card.phone.search` | — | да | да | поиск клиента по телефону |
| `card.category.guid` | Set10 (GUID категории карт) | пусто | только если «цена 3» в `external` вешается на категорию | |
| `log.payload` | — | **да** | нет | JSON запросов в логе кассы |
| `redeem.discount.type` | бухгалтерия / ОФД | `SUM` | `SUM` или `BONUSES` | тип скидки списания в чеке |
| `connection.timeout`, `read.timeout`, `redeem.timeout`, `max.attempts`, `send.refunds`, `redeem.url`, `card.config.card.info.*` | — | по умолчанию | по умолчанию | таймауты, повторы, возвраты, «Инфо по карте» |

Плюс в Set10 (не настройки плагина): плагин **последним** в порядке провайдеров лояльности; карты `999…` заведены типом с акцией «цена 3»; перезапуск кассового модуля.
