## Что НЕ проверено (важно)

| Что | Почему | Как проверить |
|---|---|---|
| Плагин на **настоящей кассе Set10** | нет доступа к кассе; поддельные чеки собраны по SDK, но реальная касса может отличаться (особенно: поле `accrueBonusAllowed`, возвращаются ли карты в `getCards()` для карт приложения) | `INTEGRATION.md`, этапы 4–5 |
| Загрузка карт приложения в Set10 | зависит от версии Set10, ответа Кристалла | вопросы в `INTEGRATION.md`, этап 3 |
| Сборка Docker-образа, HTTPS через Caddy | в среде разработки нет демона Docker | первый запуск по `DEPLOY.md` |
| Реальная отправка СМС | нет провайдера; проверен только HTTP-адаптер против фейкового провайдера | тест на своём номере (`DEPLOY.md`, п. 3.4) |
| Телефоны iOS/Safari, разные Android | проверен только Chromium; PWA и камера кассира зависят от браузера | прогнать сценарий на 2–3 реальных телефонах (список ниже) |
| Нагрузка реальных масштабов | проверены сотни запросов, не тысячи в секунду | не требуется для одного ТРЦ; при росте — тест на staging |
| Правовые вопросы | не код | юрист |

## Ручной тест на реальных телефонах (30 минут)

Выполнить на Android (Chrome) и iPhone (Safari), на мобильной сети и на Wi-Fi:

1. Открыть сайт, ввести номер, получить СМС, ввести код.
2. «Добавить на главный экран» → запуск как приложение.
3. Показать QR. Отсканировать любым сканером QR: должен показать 13 цифр, совпадающих с «Номер карты» в профиле.
4. Начислить через `/cashier` тестовый чек → приложение само показывает «Начисление прошло».
5. Выйти, войти снова: тот же баланс.
6. На `/cashier`: нажать «Сканировать QR клиента» (поддерживает Chrome на Android; в Safari сканер может не работать, тогда вводить номер вручную).
7. Яркость экрана и читаемость QR на кассовом сканере гипермаркета (важно: проверить именно на ваших сканерах).

## Запуск всего набора

```bash
cd server && npm test                 # 44 автотеста
cd .. && python3 e2e/e2e.py           # браузер
python3 e2e/plugin_live.py            # плагин + сервер (нужен собранный плагин: gradle selfTest в set10-bonus-plugin)
```
