# Идеи, которые НЕ реализованы (по вашему правилу «не добавлять без обсуждения»)

Ничего из этого в коде нет. Список для обсуждения, по убыванию пользы.

1. **Пуш-уведомления** («+120 баллов»). Сейчас приложение само показывает начисление, когда открыто. Для пушей на закрытом приложении нужен Web Push (работает в Android Chrome и в iOS 16.4+ только для установленного на экран приложения) или нативная оболочка.
2. **Нативное приложение в Google Play/RuStore/App Store** как оболочка над этим же веб-приложением и API.
3. **Приветственные баллы** за регистрацию, баллы ко дню рождения.
4. **Уровни/акции** (повышенный процент по дням, по категориям). Основа есть: процент хранится по точке, можно добавить правила «категория товара × процент», `groupCode` строки чека уже приходит.
5. **Автозагрузка карт в Set10** (ежедневный экспорт/по API), после ответа Кристалла.
6. **Вход через Telegram/VK ID** как запасной способ, если СМС дорогие.
7. **Одноразовый QR** (обновляется раз в минуту) против передачи карты другим: несовместимо со сканированием кассой Set10, нужен свой сканер/плагин карт.
8. **Бронирование боулинга и кино** (ваш план): новые экраны и маршруты, оплата баллами через готовые `quote/hold/commit`.
9. **PostgreSQL** вместо SQLite при росте или втором сервере.
10. **Отчёты**: начисления/списания по дням и точкам, экспорт в Excel, «обязательства по баллам» для бухгалтерии.
