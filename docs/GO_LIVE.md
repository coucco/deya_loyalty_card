# Переход в прод: условия, параметры, откат

## Откат (работает в любой момент)

| Уровень | Что сделать | Эффект | Когда подействует |
|---|---|---|---|
| 1. Выключатель | Set10 → «Внешние процессинги» → «Бонусы ТРЦ Дея» → `enabled` = нет | плагины ничего не делают и не ходят на сервер: ни начисления, ни списания, ни окон активации; карты и «цена 3» работают как раньше силами Set10 | после доставки настроек на кассу (перезапуск не нужен; при сомнении — перезапустить) |
| 2. Убрать из порядка | убрать плагин из порядка провайдеров лояльности и из плагинов карт | касса не вызывает плагины совсем | после доставки настроек и перезапуска |
| 3. Удалить | удалить jar с сервера Set10 и касс, перезапустить кассовый модуль | плагина нет | сразу после перезапуска |

Сбой нашего сервера кассу не останавливает: таймауты 1,5–3 с, после 3 сбоев подряд плагин 30 с не обращается к серверу, чеки копятся в очереди кассы и доезжают позже. Баллы при откате не теряются — они на сервере.

## Чем рискуем, если поставить на боевую кассу сейчас

| Риск | Почему | Что снижает |
|---|---|---|
| Работа кассы | плагин не проверен на настоящей кассе и на версии 10.4.27.0; по SDK Crystals непроверенные плагины могут ограничивать работу кассы | сначала тест 10.5.3.0, затем пилот на **одной** боевой кассе |
| Скорость подытога | при `redeem.enabled=да` подытог ждёт сервер до 1,5 с | на пилоте `redeem.enabled=нет`, пока не проверено |
| «Цена 3» | в режиме `card.mode=external` может не применяться | в бою только `internal`, пока раздел Е плана не пройден |
| Кассиры | окно «Карта не активирована» на пластике | предупредить кассиров; `card.activation=нет` до запуска СМС |
| Закон | сбор ПДн реальных клиентов без документов и уведомления РКН | не раздавать карты клиентам до юридического блока бэклога |
| Тестовый сервер | `sslip.io`, нет СМС, тестовые данные | отдельный боевой сервер (ниже) |

## Условия перехода (всё должно быть «да»)
- [ ] Тест-план на тестовой кассе пройден (разделы П–К, 3 этаж, поддержка) (`docs/TEST_PLAN.md`), журнал плагина посмотрен.
- [ ] Решён режим карт `internal` / `external` (раздел Е плана).
- [ ] Боевой сервер: домен, СМС работают, первый блок ИБ из `docs/BACKLOG.md` сделан, копии увозятся с сервера.
- [ ] Юридическое: тексты документов на месте, уведомление РКН подано.
- [ ] Боевые диапазоны карт заведены в Set10 типом с «ценой 3».

## Пилот → все кассы
1. Одна боевая касса, 1–3 дня, `redeem.enabled=нет`.
2. Каждый день: админка → «Расхождений журнала» = 0; 10 чеков вручную (баллы = сумма × %); журнал плагина без ошибок; свежая копия БД есть.
3. Включить `redeem.enabled=да` на пилотной кассе, ещё 1–2 дня.
4. Все кассы. Первую неделю — те же ежедневные проверки.

Любая проблема на кассе → уровень 1 отката, разбор по журналу плагина `plugins/deya-logs/deya-plugin.log`.
